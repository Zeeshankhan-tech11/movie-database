# Movie Database Management System

## Project Overview
The Movie Database Management System is a relational database project developed using MySQL. It stores and manages information about movies, directors, actors, genres, users, languages, and ratings.

## Technologies Used
- MySQL
- SQL
- MySQL Workbench

## Database Tables
The project contains 10 tables:

1. DIRECTOR
2. GENRE
3. ACTOR
4. USERS
5. USER_EMAIL
6. MOVIE
7. MOVIE_LANGUAGE
8. MOVIE_GENRE
9. MOVIE_ACTOR
10. RATING

## Features
- Store movie details and release years.
- Maintain director and actor information.
- Categorize movies by genre.
- Store multiple languages for movies.
- Manage user information and email addresses.
- Allow users to rate and review movies.
- Retrieve information using SQL JOIN queries.
- Calculate average movie ratings.

## How to Run
1. Install MySQL Server.
2. Open MySQL Workbench or MySQL Command Line.
3. Open `movie_database.sql`.
4. Execute the SQL script.
5. Explore the database using SELECT and JOIN queries.
